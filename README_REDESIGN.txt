# Loris Dayoub Portfolio — redesigned

## Open locally
Open `index.html` in a browser. The site uses relative file paths, so keep the folders (`images`, `photo`, and `document`) beside the HTML files.

## Main pages
- `index.html` — redesigned portfolio homepage
- `Articles.html` — press interviews, reports and PDF archive
- `photo.html` — photography gallery with image lightbox
- `Filming_Editing.html` — embedded video projects

## Design
Warm Ivory & Earth palette:
- Ivory: #F1EDE5
- Paper: #F7F4EE
- Warm beige: #E8E1D6
- Charcoal: #292824
- Copper: #A87958
